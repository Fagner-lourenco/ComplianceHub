## Guia de Deploy

### Pré-requisitos

1. **Índices Firestore:** Os 7 índices em `firestore.indexes.json` precisam ser deployados:
   ```bash
   firebase deploy --only firestore:indexes
   ```

2. **Cloud Storage:** Verificar se bucket `compliance-hub-br.appspot.com` existe e permite escrita

3. **Variáveis de Ambiente:** Confirmar que `STORAGE_BUCKET` está configurado

### Ordem de Deploy

```bash
# 1. Deploy dos índices (leva ~5-10 min para build)
firebase deploy --only firestore:indexes

# 2. Deploy das functions (inclui V2 e export assíncrono)
firebase deploy --only functions

# 3. Build e deploy do frontend
npm run build
vercel --prod --yes
```

### Rollback

```bash
# Reverter para branch main
git checkout main
firebase deploy --only functions
```
